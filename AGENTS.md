### Issue tracker

Issues live as GitHub issues in `pedro-pinheiro002/youtube-index`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles, using default label strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

Single-context layout — one `CONTEXT.md` at the root plus `docs/adr/` for decisions. See `docs/agents/domain.md`.
